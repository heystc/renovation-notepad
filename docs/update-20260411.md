# 更新说明 - 2026-04-11

本次会话更新内容：

## 1. 修复下拉菜单删除按钮被挡住问题

**问题**：笔记卡片更多按钮弹出下拉菜单，删除按钮被下方的其他笔记卡片挡住，点击无效。

**原因**：网格布局中每个卡片独立堆叠上下文，后渲染的卡片层级更高，即使菜单 z-index 较高也仍然被挡住。

**解决方案**：使用 `createPortal` 将下拉菜单直接渲染到 `document.body`，完全脱离卡片堆叠上下文，z-index `[1000]` 确保永远显示在最顶层。

**文件**：[renovation-notepad/src/components/notes/NoteCard.tsx](../renovation-notepad/src/components/notes/NoteCard.tsx)

## 2. 统一笔记卡片高度

**改动**：将所有笔记卡片设置为固定高度 `h-[200px]`，使用 flex 布局让底部信息固定在卡片底部，网格看起来更加整齐。

## 3. 图片上传支持多选

**改动**：
- 点击"插入图片"按钮现在支持选择多张图片一次性上传
- 拖拽本就支持多选，保持不变
- 修复移动端浏览器不支持动态创建 input 多选问题，改成静态隐藏 input

**文件**：[renovation-notepad/src/components/editor/MarkdownEditor.tsx](../renovation-notepad/src/components/editor/MarkdownEditor.tsx)

## 4. 修复多选上传只插入一张问题

**问题**：由于 React 闭包陷阱，循环插入多张图片时都基于初始 content 插入，最终只保留最后一张。

**解决方案**：添加 `contentRef` ref 保存最新 content 引用，每次插入都基于最新内容插入。

## 5. 添加前端图片自动压缩

**功能**：
- 上传图片前，前端自动压缩图片
- 小于 1MB 的图片不压缩，直接上传
- 大于 1MB 的图片：
  - 最大长边不超过 **2560px**（2K 清晰度）
  - JPEG 质量 **0.9**（画质损失极小）
  - 自动保持原始宽高比
  - 如果压缩后反而更大，自动使用原图
- 不依赖额外第三方库，使用浏览器原生 canvas 压缩

**文件大小**：通常几MB的原图压缩后几百KB，节省上传流量和服务器存储空间。
