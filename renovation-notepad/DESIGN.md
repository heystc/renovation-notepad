# 装修记事本应用 - 功能设计方案

## 概述

本文档详细描述装修记事本应用的三个核心功能的UI设计方案和交互流程。

---

## 功能一：预算和费用记录功能

### 1.1 页面布局

#### 预算概览页面
```
┌─────────────────────────────────────────────────────────┐
│  预算与费用管理                                          │
│  跟踪装修预算和实际支出，掌控每一分钱的去向。            │
├──────────────────┬──────────────────────────────────────┤
│                  │ 费用明细                              │
│  ┌────────────┐  │ ┌──────────────────────────────────┐ │
│  │ 预算概览    │  │ │ 项目   │ 分类 │ 房间 │ 预算 │...│ │
│  │            │  │ ├──────────────────────────────────┤ │
│  │ 总预算:    │  │ │ 客厅地砖│ 建材 │ 客厅 │ 8000 │...│ │
│  │ ¥100,000   │  │ │ 电视背景│ 施工 │ 客厅 │ 5000 │...│ │
│  │            │  │ └──────────────────────────────────┘ │
│  │ [========  │  │                                      │
│  │  45%]      │  │                                      │
│  │            │  │                                      │
│  └────────────┘  │                                      │
│                  │                                      │
│  ┌────────────┐  │                                      │
│  │ 按房间统计  │  │                                      │
│  │            │  │                                      │
│  │ 客厅 [===] │  │                                      │
│  │ 厨房 [=]   │  │                                      │
│  └────────────┘  │                                      │
│                  └──────────────────────────────────────┘
└──────────────────┴──────────────────────────────────────┘
```

### 1.2 字段设计

#### 预算项目字段
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 项目名称 | String | 是 | 费用项目名称 |
| 分类 | String | 是 | 建材/施工/定制/卫浴/家具/家电/其他 |
| 房间 | String | 否 | 关联的房间 |
| 预算金额 | Number | 是 | 预计花费 |
| 实际金额 | Number | 否 | 实际花费 |
| 状态 | Enum | 是 | 待支付/已支付 |
| 日期 | Date | 是 | 记录日期 |
| 备注 | String | 否 | 补充说明 |

### 1.3 交互流程

#### 添加费用流程
```
1. 点击"添加费用"按钮
   ↓
2. 弹出费用录入表单
   ┌─────────────────────┐
   │ 新建费用项目        │
   ├─────────────────────┤
   │ 项目名称: [______] │
   │ 分类: [下拉选择]    │
   │ 房间: [下拉选择]    │
   │ 预算: [______] 元  │
   │ 实际: [______] 元  │
   │ 状态: ○ 待支付      │
   │      ● 已支付       │
   │ [保存] [取消]       │
   └─────────────────────┘
   ↓
3. 填写信息后点击"保存"
   ↓
4. 自动更新预算统计和费用列表
```

#### 预算查看流程
```
1. 切换到"预算"视图
   ↓
2. 查看预算概览卡片
   - 总预算、已花费、剩余
   - 进度条可视化
   - 超支预警（红色显示）
   ↓
3. 查看按房间统计
   - 各房间花费进度条
   - 快速筛选房间费用
   ↓
4. 查看费用明细表格
   - 支持排序、筛选
   - 点击编辑修改
```

### 1.4 视觉设计建议

- **主色调**：蓝色（稳重、信任）+ 绿色（预算健康）+ 红色（超支警告）
- **卡片设计**：圆角矩形，轻微阴影，hover时上浮效果
- **进度条**：渐变色填充，末端圆角
- **数据展示**：
  - 金额使用千分位分隔符
  - 超支金额红色高亮
  - 预算剩余绿色显示
- **图标**：
  - 预算概览：饼图图标 📊
  - 费用记录：钞票图标 💰
  - 超支预警：警告图标 ⚠️

## 功能二：置顶功能

### 2.1 页面布局

#### 笔记卡片设计
```
┌─────────────────────────────────┐
│  [置顶标签]          [⋮]        │ ← 右上角操作菜单
│                                 │
│  [灵感]  [客厅]                 │
│                                 │
│  北欧风格电视背景墙设计         │
│                                 │
│  参考了宜家的贝达系列...        │
│                                 │
│  [进行中]  预算: ¥5,000        │
│  2026-04-01                    │
└─────────────────────────────────┘
    置顶笔记有金色边框和标签
```

### 2.2 字段设计

#### 笔记扩展字段
| 字段名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| isPinned | Boolean | false | 是否置顶 |

### 2.3 交互流程

#### 置顶操作流程
```
1. 点击笔记卡片右上角的菜单按钮 [⋮]
   ↓
2. 弹出操作菜单
   ┌─────────────────┐
   │ 📌 置顶笔记     │
   │ ─────────────   │
   │ ⏰ 设为待办     │
   │ 🔄 设为进行中   │
   │ ✅ 设为已完成   │
   └─────────────────┘
   ↓
3. 点击"置顶笔记"
   ↓
4. 笔记立即移动到列表顶部
   - 添加金色边框
   - 显示"置顶"标签
   - 菜单项变为"取消置顶"
```

#### 取消置顶流程
```
1. 点击置顶笔记的菜单按钮
   ↓
2. 选择"取消置顶"
   ↓
3. 笔记回到正常排序位置
   - 移除金色边框和标签
```

### 2.4 视觉设计建议

- **置顶标识**：
  - 卡片边框：金色/琥珀色 (#f59e0b)
  - 置顶标签：右上角倾斜标签，带图钉图标 📌
  - 轻微发光效果：box-shadow 带金色调
- **排序规则**：
  - 置顶笔记始终在顶部
  - 多个置顶笔记按时间倒序排列
  - 非置顶笔记按时间倒序排列
- **动画效果**：
  - 置顶时：卡片上浮 + 边框渐变
  - 取消置顶：平滑过渡到正常位置

| 状态 | 图标 | 颜色 | 说明 |

#### 笔记扩展字段
| 字段名 | 类型 | 说明 |
|--------|------|------|
| room | String | 关联房间（可选） |
| progress | Enum | 进度状态（待办/进行中/已完成） |

### 3.3 交互流程

#### 设置进度状态流程
```
方式一：通过菜单设置
1. 点击笔记卡片菜单 [⋮]
   ↓
2. 选择状态选项
   - 设为待办
   - 设为进行中
   - 设为已完成
   ↓
3. 状态标签立即更新

方式二：通过新建/编辑表单
1. 在表单中选择进度状态
2. 保存后显示状态标签
```

#### 房间筛选流程
```
1. 点击房间筛选按钮（如"客厅"）
   ↓
2. 按钮变为高亮状态（绿色背景）
   ↓
3. 笔记列表立即过滤，只显示该房间的笔记
   ↓
4. 可同时结合其他筛选（分类+房间+状态）
   ↓
5. 点击"全部房间"清除筛选
```

#### 状态筛选流程
```
1. 点击状态筛选按钮（如"进行中"）
   ↓
2. 按钮高亮（紫色背景）
   ↓
3. 只显示对应状态的笔记
   ↓
4. 可与房间筛选组合使用
```

#### 组合筛选示例
```
筛选条件：[分类: 费用] + [房间: 客厅] + [状态: 已完成]
         ↓
显示结果：客厅中已完成的费用记录
```

### 3.4 视觉设计建议

#### 筛选器设计
- **分类筛选**：蓝色系按钮，选中时实心蓝色
- **房间筛选**：绿色系按钮，带房间图标，选中时实心绿色
- **状态筛选**：紫色系按钮，带状态图标，选中时实心紫色
- **布局**：
  - 每个筛选组独立一行
  - 支持横向滚动（小屏幕）
  - 第一个按钮为"全部"选项

#### 状态标签设计
- **待办**：黄色背景 (#fef3c7) + 黄色文字 (#92400e)
- **进行中**：蓝色背景 (#dbeafe) + 蓝色文字 (#1e40af)
- **已完成**：绿色背景 (#d1fae5) + 绿色文字 (#065f46)
- 所有状态标签都带对应图标

#### 房间标签设计
- 灰色背景 (#f3f4f6) + 灰色文字 (#4b5563)
- 带房间图标
- 圆角矩形，小巧精致

#### 空状态设计
```
┌─────────────────────────────────┐
│                                 │
│       📭 没有找到笔记           │
│                                 │
│   尝试调整搜索条件或添加        │
│   新的笔记。                     │
│                                 │
└─────────────────────────────────┘
```

## 整体设计规范

### 颜色系统

## 总结

本设计方案完整涵盖了三个核心功能：

1. **预算和费用记录功能**：提供预算概览、费用明细、按房间统计，帮助用户掌控装修支出
2. **置顶功能**：支持重要笔记置顶显示，金色边框和标签突出标识
3. **进度状态 + 房间筛选**：三种进度状态、十种房间分类，支持灵活组合筛选

所有功能都遵循统一的设计规范，确保用户体验的一致性和专业性。
